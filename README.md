# Literary-Vault
<h1 align="center">সাহিত্যের সিন্দুক 📚</h1>

<p align="center">স্বাগতম! এটি একটি ডিজিটাল সাহিত্য ভাণ্ডার যেখানে বাংলা সাহিত্যের অমূল্য কিছু সম্পদ সংরক্ষিত আছে।</p>

## সংগ্রহের বিষয়বস্তু:
* *আধুনিক যুগ:* রবীন্দ্রনাথ ঠাকুর, তারাশঙ্কর বন্দ্যোপাধ্যায়সহ অন্যান্য লেখকদের গল্প ও উপন্যাস।
* *নাটক:* বিভিন্ন কালজয়ী বাংলা নাটক ও নাট্যকারদের কাজ।
* *গবেষণা:* সাহিত্য বিষয়ক বিভিন্ন প্রবন্ধ ও বিশ্লেষণ।

> "বই পড়ার আনন্দ সবার মাঝে ছড়িয়ে পড়ুক।"
লাইব্রেরি হচ্ছে এক-একটি মনের হাসপাতাল।
মানুষের আত্মার ব্যাধির একমাত্র ওষুধ পাওয়া যায় বইয়ের ভেতরে।
